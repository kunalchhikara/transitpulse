# TransitPulse Azure Autonomous Starter Pack

TransitPulse is a personal Azure/Microsoft Fabric-focused portfolio project demonstrating production-style batch + streaming data engineering, incident simulation, observability, Power BI and an interactive public website using synthetic data.

## Key decisions captured in this pack
- Azure/Microsoft Fabric career focus; AWS is out of scope.
- Use local development first and delay Fabric trial activation until ready.
- During the first 60 days after Fabric trial activation, use no paid Fabric capacity or paid Azure infrastructure unless explicitly approved.
- Public site retains DEMO/RECORDED mode after the trial.
- Claude Code acts as Lead with PM, Data, Web and independent QA agents.
- GitHub/CI and test evidence are the system of record, not chat claims.
- 6-7 days is an aggressive target for a strong portfolio MVP, not a guarantee of full production hardening.
